| 4720 | تم انشاء مستخدم جديد واضافته بنجاح | اذا ما كان من خلال عمليات النظام المعروفة فهذا احتمال انه حساب تم انشائه من قبل المهاجم (Persistence) ليثبت وجوده في النظام ثم محاولة إضافة هذا الحساب الى حسابات الادمنز |
| 4740 | تم اغلاق الحساب من قبل النظام | محاولات دخول فاشلة اكثر من مرة أو وجود خدمة تعمل بكلمة سر قديمة Caller) Computer Name ) هذا الحقل يخبرنا من الذ قام باغلاق الحساب ويمكن استخدامه للتفريق بين أسباب الاغلاق |

(Event id 4672) كيف نحدد اذا كان الحساب الذي اعطي الصلاحيات مشبوه Baseline

## غالبا عمليات النظام (system, LOCAL SERVICE, Network service) وحسابات الادمن المعروفة عندي يتم التغاضي عنها، او الحسابات المنتهية بـ ($) وحسابات الادمن المعروفة مش موجودة
